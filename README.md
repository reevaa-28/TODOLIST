# To-Do List Application using Python Tkinter

## 📌 Project Description
This project is a simple **To-Do List application** developed using **Python Tkinter**.
It allows the user to add, delete, and view daily tasks in a graphical user interface (GUI).

This project is created as a **beginner-level project** for **MCA 1st Year students** to understand
basic concepts of Python GUI programming.

---

## 🛠️ Technologies Used
- Python
- Tkinter
- Jupyter Notebook

---

## ✨ Features
- Add new tasks
- Delete selected tasks
- Simple and user-friendly interface

---

## ▶️ How to Run the Project
1. Install Python on your system
2. Make sure Tkinter is available
3. Open the project folder
4. Run the file:

```bash
python todo_app.py
